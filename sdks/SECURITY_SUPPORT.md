# Security support

Security support covers the studio vaai service and its SDKs for the duration of your
subscription, including any notice period and agreed transition access. During this period,
studio vaai assesses vulnerabilities and provides applicable security fixes without additional
charge. Security notices describe affected functionality and any action required from integrators.

The subscription has no scheduled end date.

Follow the SDK update instructions in the applicable security notice.
Report vulnerabilities through [Security](https://studio-vaai.com/security).
